突発型EEJのイベント（図\ref{tab:sudden_events}参照）の解析期間（2009年〜2020年）において、特に2018年12月20日、2019年11月11日、および2019年11月24日の事例では、Dip観測点におけるEUELの減少幅が他の突発型イベントに比べて極めて大きい傾向が見られた。
本論文の考察では、J-SolsticeにおいてSq電流が弱まることがCEJの発生要因の一つである可能性を指摘したが、
これらの大きな減少を示したイベントはいずれもD-Solstice付近で発生しており、
Sq電流の季節変動に起因するものではないと考えられる。

また、各イベント発生日における月齢（Lunar age）は以下の通りである。
\begin{itemize}
    \item 2018-12-20: 10.3
    \item 2019-11-11: 11.2
    \item 2019-11-24: 21.8
\end{itemize}
これらは月潮汐効果によって西向き電流がある程度強化される時期ではあるものの、その効果が最大となる時期（ピーク）とは一致していない。
したがって、これらのイベントで観測されたEUELの特異な減少は、
Sq電流の弱化や月潮汐効果だけでは説明がつかず、未解明の別要因が寄与している可能性が示唆される。
